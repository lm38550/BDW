## ✨ Projet de LIFBDW

Ce projet à été crée par Sasha DJAMAKORZIAN et Louis MOREL dans le cadre de l'UE Base De Données Et Programmation Web (LIFBDW)  
Date de publication : 28/04/2023

## 🔧 Languages et logiciels utilisés pour le développement

HTML  
CSS  
PHP  
FileZilla  

## 🧠 Compétences étudiés

- Utilisation du système MVC (Modele - Vue - Controleur)
- Intégration et communication avec une base de donnée SQL
- Création d'un site internet pour la manipulation / visualisation des données

## Arborescence

`WEB/` contient tout la partie du site web.  
`CODE_BASE.sql` contient la base de donnée SQL.  
`bdw.loo` contient le diagramme de relations généré grâce au logiciel Looping, vous pouvez voir le résultat final dans `bdw.jpg`.
